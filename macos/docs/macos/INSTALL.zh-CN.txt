ChatGPT assistant 0.1.2 — macOS Apple Silicon

一、适用设备
• Apple 芯片 Mac（M1/M2/M3/M4 等），macOS 13 或更新版本。
• 此包不支持 Intel Mac。
• 已内置 Python 运行环境，不需要自行安装 Python、Codex、ChatGPT 桌面版或 Chrome。
• 使用 AI 功能需要联网，以及你自己的可用 ChatGPT 授权或 API 服务账号。

二、安装和首次打开
1. 从项目的 GitHub Releases 下载 ChatGPT-assistant-arm64.zip。
2. 解压，将“ChatGPT assistant.app”拖入“应用程序”文件夹，然后打开。
3. 此 GitHub 版本使用固定本地证书签名，尚未经过 Apple Developer ID 公证。macOS 可能提示无法验证开发者。
4. 确认下载来自项目官方 Release 后，先尝试打开一次，再进入“系统设置 → 隐私与安全性”，找到该应用的拦截提示，点击“仍要打开”，按系统提示确认。
5. 若系统提示恶意软件、文件损坏，或始终没有“仍要打开”，请停止安装并核对下载来源与 SHA256.txt，向项目反馈；不要关闭 Gatekeeper、SIP 或执行网上的全局安全关闭命令。

三、使用 ChatGPT 授权
通过 ChatGPT 授权使用本软件，消耗的是你的 Codex / ChatGPT Work 计划额度，不是普通 ChatGPT 网页聊天的消息额度。具体可用额度以你的账号授权页面为准。
1. 首次启动会展开底部设置区域。点击“ChatGPT 授权”。
2. 应用会打开系统默认浏览器。登录你自己的 ChatGPT 账号，在官方授权页确认是否允许使用套餐额度。
3. 授权结束后回到应用；模型目录会自动尝试加载，也可点击主页面“刷新模型”。选择账号可用的模型，然后发送文字。
4. ChatGPT 套餐接入受 OpenAI 的账号资格、地区、模型权限与额度限制；登录成功不代表所有模型均可使用。若无可用套餐权限，可使用自己的 API 服务。
5. 授权只针对本应用，不读取其他软件的登录配置。凭据保存在本机 macOS 钥匙串中。

四、使用自定义 API
自定义 API 使用对应服务商的 API 账户额度，费用和限制以该服务商为准。
1. 展开“设置与账户”，点击“API 设置”。
2. 选择服务商，填写服务商给出的兼容服务地址和你自己的 API Key。
3. 服务地址应为 API Base URL（通常以 /v1 结尾），不要填到 /chat/completions；Qwen 占位地址需要替换为你的实际服务地址。
4. 点击“刷新模型”，从下拉列表选择；也可以直接输入模型 ID。部分服务不提供模型列表接口，这种情况可手动填写。
5. 点击“保存并启用”。服务商可能计费，请自行检查额度。
6. API 模型和 ChatGPT 模型分别保存；点击“ChatGPT 授权”可切回 ChatGPT 模式。
7. API Key 留空只会保留同一服务地址已经保存的密钥，不会借用其他地址的密钥。

五、截图权限
1. 点击“框选截图”，按系统提示授予“屏幕与系统音频录制”（部分系统称“屏幕录制”）权限。
2. 若应用不在列表中，点击“＋”，选择你刚安装到“应用程序”中的 ChatGPT assistant.app 并开启。
3. 按系统提示退出并重新打开。关闭窗口只会收起界面，不等于退出；可使用应用菜单退出。
4. 拖动鼠标框选区域。看到预览和“已截图，尚未发送”后，说明截图成功。只有点击发送或翻译时才会把截图交给你选择的服务。
5. 使用支持图片的模型处理截图；主页面会显示图片能力，未明确报告能力的 API 模型会标为未知。
6. 正常更新沿用相同签名身份；首次安装、未来更换签名证书或 macOS 自身的权限政策仍可能要求确认。

六、常用操作
• 默认 Ctrl+Shift+Space 截图；Enter 发送；Shift+Enter 换行。可在“快捷键设置”中修改。
• A− / A+ 调整回答大小；“放大截图”查看截图；“编辑源码”修改 Markdown/LaTeX，“预览公式”查看排版。
• 默认头像为“自”字。更换头像后，悬浮窗和 Dock 会跟随当前用户的头像变化；应用文件保留默认“自”图标。
• 自定义头像、模型、快捷键和授权仅在使用者本机保存。

七、更新
完全退出应用，用新版替换同一安装位置的旧应用，再打开。不要同时运行多份不同目录的副本。替换 .app 不会删除你本机的头像、模型选择和钥匙串授权。
