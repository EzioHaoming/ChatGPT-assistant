# ChatGPT assistant · macOS

支持 Apple 芯片 Mac（M1 及更新芯片）、macOS 13+。

## 安装与使用

解压程序包，将 ChatGPT assistant.app 拖入“应用程序”后打开。首次打开如被系统拦截，请确认来源后按“系统设置 → 隐私与安全性 → 仍要打开”操作。本版本尚未经过 Apple 公证。

点击“ChatGPT 授权”登录自己的账号，选择模型后即可提问。ChatGPT 授权使用 Codex / ChatGPT Work 计划额度；自定义 API 使用对应服务商的 API 账户额度。使用 API 时在“API 设置”填写自己的地址和 Key，并选择模型。

截图需授予屏幕录制权限。框选后点击翻译或发送；支持回答复制、公式显示、缩放、自定义快捷键和头像。更新前退出应用，在原位置替换应用再打开。
